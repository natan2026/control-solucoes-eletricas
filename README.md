# CONTROL Soluções Elétricas

Site institucional da CONTROL Soluções Elétricas, com atendimento no Vale do Paraíba.

## Conteúdo

- Apresentação da empresa e da equipe.
- Dez áreas de atuação publicadas, com espaço para expansão futura.
- Galeria preparada para fotografias reais dos serviços.
- Contato pelo WhatsApp.

## Publicação

Site estático em HTML, CSS e JavaScript. O GitHub Pages publica a raiz da branch `main`.

Os serviços serão preenchidos posteriormente, conforme definição da empresa. Os campos de e-mail, endereço completo e perfis sociais aguardam informação.

## Identidade

A logomarca e os conteúdos institucionais pertencem à CONTROL Soluções Elétricas.
